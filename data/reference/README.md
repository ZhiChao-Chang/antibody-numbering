# Framework references

`independent_numbering_public_20261109/framework_templates.json` contains the framework sequences, chain metadata, and five-scheme coordinate mappings used by the CLI and browser tool.

Individual source IDs and a short attribution record are retained in the JSON. Public sequence sources include [PDB](https://www.rcsb.org/pages/policies), [SAbDab2](https://sabdab.opig.stats.ox.ac.uk/about), and [OAS](https://opig.stats.ox.ac.uk/webapps/oas/). PDB archive data use CC0; SAbDab2/OAS source data use [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
